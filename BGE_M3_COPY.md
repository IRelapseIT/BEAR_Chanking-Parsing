# Отдельная копия BEAR для BGE-M3

Источник: текущие локальные исходники `D:/CODEX/BEAR/BEAR_Chanking-Parsing`, включая незакоммиченный EmbeddingPipeline. Это самостоятельная копия файлов без Git-истории, окружений, старых моделей, рабочих документов и баз данных.

Основная модель по умолчанию: `BAAI/bge-m3`, 1024 компоненты, пустые query/document/similarity префиксы. Рабочий предел профиля — 512 токенов, стандартные чанки — target 320 / max 480. Ревизия фиксируется в `models/bge-m3/bear-model.json` при подготовке модели.

Переключены значения по умолчанию подготовки модели, API/CLI и загрузка профиля Fusion. Рабочая модель определяется BGE-M3 manifest. Общая модель данных `EmbeddingProfile` сохраняет прежние E5-defaults для совместимости; runtime этой копии загружает конкретный BGE-M3 профиль из manifest, а не создаёт профиль по этим defaults. Шаблон E5 оставлен для явного использования и исторических тестов. Исторические отчёты, фикстуры и Qwen smoke-скрипт сохранены как материалы исходной версии; они не подтверждают качество BGE-M3.

## Изолированные адреса и данные

- Модель и токенизатор: `models/bge-m3`.
- Состояние и оригиналы: `state-bge-m3`.
- Endpoint модели: `http://127.0.0.1:7998/v1`, served-model ID `BAAI/bge-m3`.
- Qdrant: `http://127.0.0.1:6335`, новая коллекция `bear_bge_m3_<embedding_profile_id>`.
- Для будущего отдельного Qdrant используйте собственный storage этой копии, не каталог основной системы.

Ни один сервер автоматически не запускается. Не направляйте этот профиль в старый Qwen/E5 endpoint. Одинаковый размер векторов не доказывает совпадение моделей.

## Локальный запуск — вручную

Из этой папки создайте отдельное Python 3.12 окружение и установите пакеты:

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -c constraints-py312-tested.txt -e './bear-text-beta[dev,local-inference]' -e './bear-fusion-lab[demo,acceptance]'
. ./use-bge-m3.ps1
```

После отдельной настройки сервера модели на закреплённых весах и отдельного Qdrant можно запускать API на другом порту:

```powershell
./.venv/Scripts/python.exe -m uvicorn bear_text_beta.api:app --host 127.0.0.1 --port 8002
```

Для CLI передавайте абсолютные пути, если команда выполняется не из корня копии:

```powershell
./.venv/Scripts/bear.exe --model-dir models/bge-m3 --state-dir state-bge-m3 <команда>
```

Исходные правила PDF/Fusion, резервного разбора и отдельные process/index/search этапы сохранены из локального снимка. Эта копия переключает модель и изолирует конфигурацию; она не изменяет правила приёмки документов и автоматической индексации.
