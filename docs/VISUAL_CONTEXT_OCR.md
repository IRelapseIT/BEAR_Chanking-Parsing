# Изображения и их контекст в BEAR

Подход проверен на исходном `ContextExtractor` RAG-Anything из коммита
`eb7a670f724e59056b6a08f7016d753226a865ee`. На готовых блоках сравнили окно
той же страницы и окно с соседней страницей. Оба режима сохранили заданную
подпись. Второй включил посторонний текст с соседней страницы.
[Документация RAG-Anything](https://github.com/HKUDS/RAG-Anything/blob/eb7a670f724e59056b6a08f7016d753226a865ee/docs/context_aware_processing.md)

BEAR сохраняет встроенное изображение как отдельный блок `IMAGE`. PDF-источник
содержит страницу и прямоугольник в пунктах. DOCX API сохраняет адрес объекта,
отношение OOXML, ссылку на файл внутри исходного архива и авторский alt-текст,
если он присутствует. Подпись связывается с картинкой по соседству. Для PDF
учитываются страница, горизонтальное пересечение и вертикальное расстояние,
для DOCX — часть архива и раздел. Неоднозначная подпись остаётся без связи.

Tesseract извлекает видимую надпись в `metadata.image_ocr`. Новые наблюдения
доступны при проверке и не копируются в текст чанка. Встроенные изображения
сохраняют статус review. Полностраничные сканы идут по существующему пути
двух OCR, а при выборе Docling первичные наблюдения сохраняются в
`primary_visual_regions`.

На трёх контролях до изменений сохранено 0 из 3 визуальных блоков. После
изменений сохранено 3 из 3 блоков и подписей. Обе надписи `NORD 608`
распознаны точно. Для эмблемы без текста получен `no_text_detected`.
Текстовый слой во всех трёх документах совпал до и после обработки.
На странице 3 статьи *Attention Is All You Need* сохранены область схемы
и её исходная подпись. OCR надписей внутри схемы содержит ошибки.
[Статья](https://papers.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf)

Артефакты находятся в `verification/visual-context`. `baseline.json` и
`report.json` содержат результаты до и после. `rag-anything-context.json`
содержит выход исходных классов RAG-Anything, а `attention-page-3.json` —
проверку реальной схемы. В этом опыте оценивались связь с источником и OCR
надписей. Идентификация бренда по эмблеме, описание схем визуальной моделью,
полный запуск RAG-Anything и MinerU не проверялись.
