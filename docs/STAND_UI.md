# Интерфейс локального стенда

FastAPI раздаёт статические HTML, CSS и JavaScript из пакета BEAR. Экран использует API загрузки, job manifest и сохранённые результаты worker. Пакетная загрузка отправляет один запрос на файл, чтобы ошибки и прогресс были видны отдельно. История документов и прогонов восстанавливается из manifest. Область tenant/space передаётся с запросами просмотра и поиска.

Верхняя панель показывает рабочую область и готовность сервисов. Навигация открывает обзор, загрузку, инспектор документа, чанкинг, индекс, поиск и прогоны. Инспектор сопоставляет растр страницы с блоками, которые можно фильтровать и листать. На узком экране панели складываются вертикально. Состояния загрузки, ошибки и отсутствующих данных отображаются рядом с действием. Полный текст и JSON доступны из сохранённого результата и из экспорта.

Оформление использует тёмный сине-зелёный заголовок, светлый рабочий фон и янтарный цвет предупреждений. Артефакты отображаются как текст через DOM. Для оригинала PDF и изображений используется растровый маршрут. Исходные офисные файлы доступны для скачивания.
