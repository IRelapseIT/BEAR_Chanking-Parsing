# Форматы документов в локальном стенде BEAR

`GET /v1/formats` перечисляет маршруты, зарегистрированные в запущенном API. Доступность Tesseract, PaddleOCR и LibreOffice зависит от локальной установки. Загруженный файл, извлечённые блоки и индекс хранятся отдельно.

| Формат | Маршрут | Что сохраняется | Ограничения |
| --- | --- | --- | --- |
| TXT, MD, HTML, HTM | Текстовый и структурные адаптеры BEAR | Текст, порядок блоков, разделы и доступные ссылки на источник | Для TXT основная кодировка UTF-8 или Unicode с BOM. Windows-1251 требуется разрешить явно. |
| DOCX | OOXML и табличный процессор BEAR | Текст, абзацы, заголовки, доступные вложения и таблицы | Просмотр структуры и скачивание оригинала. Сложные конструкции могут сопровождаться предупреждениями. |
| PDF | pdfplumber, PDFium, Tesseract, настроенные PaddleOCR и Docling | Страницы, извлечённые блоки, таблицы, координаты и сведения о маршруте | Полнота и точность OCR требуют отдельной проверки по эталону. |
| CSV, TSV | `csv.reader`, строгий разбор кавычек | Пустые записи и значения, переводы строк внутри поля, номера физических строк, координаты полей | Для TSV используется табуляция. CSV распознаёт запятую и точку с запятой. Роль первой строки остаётся неопределённой. |
| XLSX | `openpyxl 3.1.5`, MIT | Листы по порядку, координаты и объединения ячеек, скрытые листы и строки, даты, числа, формулы и сохранённый кэш | Формулы не пересчитываются. Кэш может отсутствовать или устареть. Формат отображения сохраняется отдельно, простые маски из нулей применяются к значениям. Сложное оформление и фигуры остаются доступны в оригинале. |
| XLS | `xlrd 2.0.2`, BSD | Листы по порядку, диапазоны объединений, типы значений, координаты и видимость | Поддерживаются двоичные книги Excel в составном контейнере OLE. `xlrd` читает сохранённые результаты формул, исходные формулы и встроенные объекты не извлекаются. |
| PNG, JPG, JPEG | Pillow, Tesseract, резервный PaddleOCR при пустом результате или ошибке | Оригинал, размеры после EXIF-поворота, распознанные строки, bbox в пикселях, оценки OCR | Автоматическая ориентация по EXIF. Анимированный PNG обрабатывается по первому кадру с предупреждением. Оригинал остаётся доступен при пустом OCR. |
| XML | `lxml` с отключённым разрешением внешних ресурсов | Порядок текста, вложенность узлов, атрибуты и пути до элементов | DTD запрещены. Атрибуты доступны как структурные данные. XML автоматически не преобразуется в таблицы. |
| DOC, ODT, RTF | LibreOffice в отдельном процессе, затем канонический DOCX-парсер | Оригинал, извлечённая структура, версия конвертера и координаты в производном DOCX | Требуется LibreOffice. Для DOC поддерживается классический бинарный Word 97–2003. Координаты после конвертации относятся к производной структуре. |

Для табличных форматов `table_cells` содержит значения, нулевые индексы и размеры объединений. `cell_origins` сопоставляет идентификатор ячейки с координатами исходного файла. В CSV и TSV это номер записи, столбца и диапазон физических строк. В Excel дополнительно доступны адрес вида `B12`, имя листа и тип значения. Сведения о листе сохраняются и для пустого листа.

## Повтор проверки

Запусти стенд и укажи его локальный адрес. Из корня проекта с установленными зависимостями разработки выполни:

```powershell
$env:BEAR_STAND_URL = 'http://127.0.0.1:8002'
./.venv/Scripts/python.exe -m pytest -q -s bear-text-beta/tests/test_stand_formats_live.py
```

Тесты загружают реальные файлы форматов, созданные для проверки, ожидают worker и проверяют результат поиска через Infinity с BGE-M3 и Qdrant. Скрипт выводит идентификатор задания, время, число чанков и область `format-verification`, в которой можно открыть результаты. Для тестового двоичного DOC нужен LibreOffice в среде запуска тестов. Независимая проверка конвертера запускается с `BEAR_TEST_LIBREOFFICE=1`.
