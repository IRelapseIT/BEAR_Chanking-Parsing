# Локальное подключение bear_embedding

Источник: [andreysokolov-ctrl/bear_embedding](https://github.com/andreysokolov-ctrl/bear_embedding/tree/a4616fad125101a580708df6c6ea73ab62878dff), commit `a4616fad125101a580708df6c6ea73ab62878dff`. Его база — BEAR `c2447d4`; перенос выполнен выборочно поверх текущего BEAR `5c0ffe0`.

## Что подключено

- `embedding_pipeline.py`: `EmbeddingPipeline`, DTO запросов и событий, ограниченный LRU-кэш векторов.
- `model_profiles.py`: шаблоны E5-small и BGE-M3.
- `prepare-model --model e5-small|bge-m3`: подготовка выбранного токенизатора с фиксацией ревизии и отказом при использовании каталога другой модели.
- `Services`: один экземпляр `EmbeddingPipeline` передаётся чанкеру и индексатору. В режимах `offline` / `test_counter` инференс отключён.
- Тесты исходного embedding-слоя и дополнительные проверки подключения к текущему runtime.

Перенесённые модули взяты из указанного источника. Адаптация runtime и дополнительные интеграционные проверки выполнены в текущем проекте. Старые версии парсеров, индексатора, runtime и удалённого чанкера из источника не заменяют исправленное ядро. Модуль метрик retrieval и сторонние отчёты не переносились: подключение векторизации их не требует.

## Поток данных

```text
Файл → парсер и чанкер BEAR → ProcessingResult
    → IndexingService → EmbeddingPipeline → Infinity → проверенные L2-векторы
    → Qdrant → проверка записи → активация поколения

Вопрос → IndexingService.search → EmbeddingPipeline
    → NFC + нормализация пробелов → Infinity → Qdrant
    → фильтры tenant / space / активное поколение / embedding-профиль
```

Документы передаются как готовый `chunk.embedding_text`: форматирование кода и контекст раздела сохраняются. Модельные префиксы добавляет только `InfinityEmbeddingProvider`. Для вопросов отдельно нормализуются Unicode и пробелы. Векторы проверяются и нормализуются; одинаковые подготовленные строки вычисляются один раз. Кэш разделён по embedding-профилю и назначению.

`vectorize_chunks(result)` возвращает `EmbeddedChunk[]`, но не записывает Qdrant и не активирует поколение. Для штатной индексации нужен `Services.indexer.index(result)`: он выполняет существующие проверки checkpoint, диапазонов, покрытия, нетекстовых блоков и поколения. `vectorize_envelope` отклоняет непроверенный экспериментальный результат Fusion; приёмка источника не подменяется векторизацией.

## Использование

E5-small остаётся моделью по умолчанию. При подготовленном E5-токенизаторе и работающем Infinity отдельного переключателя для нового слоя не требуется.

Для BGE-M3 из корня репозитория:

```powershell
bear --model-dir models/bge-m3 prepare-model --model bge-m3
$env:BEAR_MODEL_DIR = "models/bge-m3"
$env:BEAR_INFINITY_URL = "http://127.0.0.1:7997/v1"
$env:BEAR_INFINITY_MODEL = "BAAI/bge-m3"
$env:BEAR_QDRANT_URL = "http://127.0.0.1:6333"
$env:BEAR_QDRANT_COLLECTION = "bear_bge_m3_pipeline_v1"
```

Подготовка без `--weights` скачивает токенизатор, а не запускает модель. Infinity разворачивается отдельно с соответствующей моделью и закреплённой ревизией. BGE-M3 использует 1024 компоненты и пустые префиксы; её шаблон имеет консервативный лимит 512 токенов, текущий провайдер — 480. У E5-small остаются 384 компоненты и префиксы `query:` / `passage:`.

```powershell
bear --model-dir models/bge-m3 process input.txt --document demo --mode token --output state/demo.json
bear --model-dir models/bge-m3 index state/demo.json
bear --model-dir models/bge-m3 search "Условия возврата?"
```

При смене модели корпус нужно обработать и проиндексировать заново. Если коллекция явно не задана, для моделей кроме E5 runtime выбирает имя с идентификатором профиля. Существующий адаптер Qdrant проверяет размерность коллекции. `GET /models` проверяет served-model ID, но не доказывает совпадение весов удалённого сервера с локально закреплённой ревизией.

Ключи: `BEAR_INFINITY_API_KEY` и `BEAR_QDRANT_API_KEY`. Кэш хранится только в памяти процесса. На одном экземпляре inference сериализуется; `aembed()` выносит синхронную работу в поток, но не создаёт асинхронный пул.

## Проверки

```powershell
python -m pytest bear-text-beta/tests bear-fusion-lab/tests -q
```

Проверяются нормализация запросов, сохранение исходного документа, однократное добавление префиксов, кэш, порядок батча, профили, отказ на некорректных векторах и превышении лимита до инференса. Интеграционные тесты проверяют подключение к `Services`, передачу валидаторов таблиц и офлайн-режим. HTTP-заглушки не измеряют качество моделей.

Для проверки реальных локальных весов служит [live_embedding.py](../verification/embedding/live_embedding.py). Он требует CPU PyTorch, локальные веса Qwen3-Embedding-0.6B, transformers и native Qdrant. Скрипт поднимает временный Infinity-совместимый endpoint на настоящей модели и отдельный Qdrant с временным хранилищем, проверяет текущий `Services`, затем завершает свои сервисы. Модели скрипт не скачивает. Серверный пакет Infinity в этой проверке не запускается.

```powershell
python verification/embedding/live_embedding.py --model-dir <локальный-snapshot-Qwen3> --qdrant-exe <путь-к-qdrant.exe> --report <путь-к-report.json>
```

Реальный инференс BGE-M3, нагрузочный тест и оценка качества на размеченном корпусе требуют отдельных запусков. Успех контрактных тестов не является результатом такой оценки.

- Полная регрессия: **232 passed**, одно предупреждение зависимости Starlette/httpx.
- Ruff для добавленных и изменённых Python-модулей: **All checks passed**.
- [Реальный smoke-отчёт](../verification/embedding/live-report.json): Qwen3-Embedding-0.6B, CPU, закреплённая ревизия `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`, 1024 компоненты; 3 документа, 3 чанка, 6 HTTP-запросов инференса.
- Правильный документ о возврате найден первым. Прошли проверки tenant/space, повторного запроса из кэша, единичной нормы, отказа на oversized-входе до HTTP, сохранения старого поколения при сбое записи и активации нового после retry.
- BGE-M3 проверена контрактными тестами на заглушках; реальные веса BGE-M3 не использовались. В реальном smoke использован временный совместимый endpoint, а не серверный пакет Infinity. Временные сервисы завершены.
