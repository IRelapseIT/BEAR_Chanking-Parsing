# Подтверждённые разрывы и выполненные изменения

| Проблема | Последствие | Исправление | Проверка |
| --- | --- | --- | --- |
| API process/index были раздельными | Загрузка сама не давала поиск | `/v1/documents`, durable queue, auto-index worker | Настоящий API-корпус и тесты ingestion |
| PDF существовал только в Fusion-демо | Общее API его не принимало | PDFParser подключён в ParsingPipeline | HTTP PDF/скан, прежние fallback-тесты сохранены |
| DOCX API требовал внешнего Dedoc | Нельзя было воспроизвести минимальный запуск | Нативный ограниченный OOXML, восстановление таблиц Fusion | DOCX headers/lists/merged/long cells/embedded controls |
| Экспериментальный Fusion не имел политики автоприёмки | Нельзя безопасно поставить `accepted_for_indexing=True` | Отдельная operational policy с review и сохранением `source_fidelity=unverified` | Неодобренный результат блокируется индексатором |
| Lease защищала только processing checkpoint | Нужна защита последующей активации | Fencing начала индексации/активации и desired generation | Старые и новые lease-тесты; HTTP обновление/retry |
| Payload не содержал SourceLocator | В поиске терялась страница/bbox | `sources` с геометрией и диапазонами | Настоящие search responses и corpus report |
| Проверялся совместимый сервер, а не Infinity | Не доказана серверная интеграция | Отдельный Infinity 0.0.77, dependency fixes, реальные веса | models/embeddings, reference vectors, реальные отказы |
| Общего исполняемого запуска не было | Нет воспроизводимого end-to-end пути | Два окружения, pinned requirements, PID registry/start/stop | Полный restart и сохранение поиска |

Переиспользованы без повторного выполнения большого сравнения: весовая ревизия и SHA256, pooling BGE-M3, исправления локального сервера, сравнение BGE/Qwen на 174 документах из чата «ТЕСТЫ». `workflow_preservation.py` подтвердил сохранность 43 исходных файлов основной версии и отсутствие неожиданных изменений относительно 44 исходников BGE-снимка. Намеренно изменены существующие API/runtime/indexing/storage/process_worker; остальная работа с моделями сохранена.

Не закрытая проблема качества: текущая консервативная политика отправляет OCR, embedded objects и некоторые Markdown-изображения в review. Убирать этот барьер ради процента нельзя. Для достижения согласованной цели 90% нужен репрезентативный корпус с разметкой существенности таких объектов, отдельная приёмка OCR/таблиц и повторная оценка; текущий результат ниже цели.
